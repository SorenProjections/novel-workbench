# 术语表

## API

前端与后端约定好的通信入口。这个项目主要通过 HTTP 路由接收操作。

## FastAPI

当前 Python 后端使用的 Web 框架，负责路由、参数解析和响应。

## React

当前页面使用的前端框架，负责界面组件和浏览器状态。

## SSE / EventSource

服务器向浏览器持续发送事件的机制。这里用于显示长时间模型调用的进度、心跳、结果和错误。

## Orchestrator

编排器。决定当前能做什么、读取哪些上游数据、调用哪个生成图，以及结果保存到哪里。

## Graph

一个阶段内的生成逻辑，例如作品基座、全书规划、卷规划或事件展开。它不是页面上的关系图。

## Prompt

发送给模型的任务说明模板。模板会与当前项目数据结合后渲染成最终输入。

## StepSpec

某一步的执行契约，描述提示词、输出结构、预算和提交类型等配置。

## Schema

结构约束。用于判断模型输出是否具有系统要求的字段和类型。

## Adapter

适配器。把项目内部统一调用转换为某个外部供应商的 API 请求。更换模型供应商时应尽量把变化限制在适配层。

## staging / 暂存区

尚未批准的审核稿。生成成功后先进入这里，不应直接影响后续权威数据。

## authority / 权威层

已经经过批准、可以被后续生成读取的正式资产。

## AuthObject

权威资产在 Python 中的核心数据模型，包含对象类型、内容、版本和提交来源等信息。

## StagingPacket

一张可审核任务的数据包，包含可编辑内容、内部依据、状态、运行 ID 和暂存 ID。

## commit / 提交

把经过校验和批准的内容写入正式存储。它不等于 Git commit；需要根据上下文区分。

## 原子写入

先完整写好临时内容，再一次性替换目标文件，减少程序中断造成半个 JSON 文件的风险。

## 文件锁

同一时刻只允许一个执行者修改某个文件，降低并发覆盖。

## Token

模型处理文本时使用的计量单位。输入和输出都会产生 Token 消耗。

## 超时

等待外部模型响应超过允许时长后终止本次请求。超时不代表提示词一定错误。

## 重试

调用失败后再次请求。重试可能提高成功率，也会增加时间、费用和重复执行风险。

## 缓存

同样输入已经获得过结果时直接复用，避免重复请求模型。

## 幂等

同一操作重复执行多次，最终效果仍与执行一次相同。支付、批准和任务提交尤其需要关注幂等性。

## 陈旧写入

审核稿基于旧版本生成，但批准时正式数据已经更新。若不检查版本，旧内容可能覆盖新内容。

## BYOK

Bring Your Own Key，用户提供自己的模型 API Key。它能转移模型费用，但仍需要安全保存密钥。
